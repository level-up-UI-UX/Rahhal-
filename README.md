# 📱 Rahal Mobile App — UI/UX Case Study

## 🧾 Project Overview

**Rahal** is a mobile application UI/UX case study focused on delivering a smooth, user-centered experience for travelers. The project presents the complete design process, starting from research and wireframing to high-fidelity visual design and an interactive prototype.

This repository showcases the **design thinking**, **user flows**, and **visual system** behind the Rahal mobile application.

---

## 🎯 Project Objectives

* Design a clean and intuitive mobile application interface
* Improve usability and navigation flow
* Apply UI/UX principles and best practices
* Create a realistic, clickable interactive prototype
* Present the project in a clear and professional format

## 🧠 Design Process

### 1️⃣ Research & Discovery

* Analyzed similar travel and tourism applications
* Identified user needs and pain points
* Defined core features and goals

### 2️⃣ Wireframing

* Created low-fidelity wireframes for key screens
* Defined primary user flows
* Focused on clarity and simplicity

### 3️⃣ Visual Design

* Designed high-fidelity UI screens using **Figma**
* Applied a consistent color palette and typography
* Followed a modern and accessible design approach

### 4️⃣ Prototyping

* Built a clickable interactive prototype using Figma
* Connected screens to simulate a real user experience

---

## ✨ Key Features & Capabilities

* Clean and modern user interface
* Clear visual hierarchy
* Consistent spacing and grid system
* Simple and user-friendly authentication screens
* Visual style inspired by travel and tourism

### 🧭 Core App Features

* 🎟️ **Ticket Booking**
  Users can book tickets for tourist attractions and activities directly through the app using a simple and clear flow.

* 🧑‍🏫 **Tour Guide Booking**
  Users can choose and book a certified tour guide, view guide details, and explore guided tour options.

* 📍 **Landmark Discovery**
  The app allows users to explore tourist landmarks with images and detailed descriptions.

* 📷 **Scanning Feature (QR Code / Landmark Scan)**
  Users can scan a QR code or capture a landmark using the camera to instantly receive related information.

* ℹ️ **Detailed Landmark Information**
  After scanning, the app displays historical and cultural information, location details, and visiting tips.
